settingsQuick Settings

Main feature toggles. Changes require a restart to take effect.

Custom Crosshair

Toggle crosshair display on/off. See "Crosshair" section for details.

Custom CSS

Enable/disable custom CSS styling. See "Custom CSS" section.

Resource Swapper

Enable/disable texture and audio replacement. See "Swap" section. Requires restart.

Ad Blocker

Enable/disable ad and tracker blocking. See "Ad Blocker" section. Requires restart.

Unlimited FPS

Remove FPS cap (same as in Advanced settings). Requires restart.

crosshairsCrosshair

To use custom crosshair, first turn on "Custom Crosshair" in Quick Settings.

Crosshair Type

Choose how to load the crosshair image:

  • URL: Paste a direct image link (PNG/GIF recommended).
  • Local File: Select an image file from your PC (PNG/GIF/APNG supported).
  • List: Pick from images stored in the swap folder.

URL / Local File

Enter the image URL or select a local file.

Size Settings

Enable "Auto Size" to use the image's native resolution. Disable to set width and height manually (1px–1024px).

Opacity

Set transparency (0 = fully transparent, 1 = fully opaque).

Rendering Method

Choose how the image scales:

  • Pixelated: Preserves pixel art look with nearest-neighbor scaling.
  • Sharp Edges: Keeps edges crisp without blurring.

brushCustom CSS

To use custom CSS, first enable "Custom CSS" in Quick Settings.

CSS Source

Choose how to load your CSS file:

  • URL: Link to a CSS file online (must support CORS, e.g., GitHub Pages).
  • Local File: Select a .css file from your PC.
  • List: Pick a CSS file stored in the swap folder.

folder_openSwap (Resource Replacement)

To use the swapper, first enable "Resource Swapper" in Quick Settings. Changes require a restart.

Folder Location

On first launch, VoxMate creates documents/vmc-swap. Inside, you'll find "css" and "crosshair" folders. Place your files there.

Use Default List

Use the built-in swapper-default.json that maps game URLs to local filenames.

Use User List

Create your own swapper-user.json in documents/vmc-swap to add or override mappings. Format:

{ "https://voxiom.io/package/aef55bdd0c3c3c3734f8.png": "soldier_red.png", "https://voxiom.io/sound/weapon.ogg": "weapon_custom.ogg" }

If both lists contain the same URL, the user list takes priority.

blockAd Blocker

To use the ad blocker, first enable "Ad Blocker" in Quick Settings. Changes require a restart.

Use Default Block List

Use the built-in adblock-default.json (list of domains to block).

Use User List

Create your own adblock-user.json in documents/vmc-swap with the format:

{ "urls": [ "example.com", "ads.com", "tracking-site.com" ] }

tuneAdvanced Settings

These are advanced options. Most require a restart. Change with caution.

Unlimited FPS

Remove the FPS cap.

Discord Rich Presence

Show your game status on your Discord profile.

Disable GPU VSync

Turn off vertical sync to reduce input lag.

Change ANGLE Backend

Switch the graphics backend (OpenGL, Direct3D, etc.).

In-Process GPU

Run GPU processes inside the main process (experimental; may improve performance).

QUIC Protocol

Use QUIC for network traffic.

GPU Rasterization

Use the GPU for rasterization steps.

Pointer Lock Options

Allow the game to lock the mouse pointer (FPS-style controls).

Heavy Ad Intervention

Enable Chrome's heavy ad mitigation.

Ignore GPU Blocklist

Force-use GPUs that are normally blocked.

Zero Copy Transfer

Optimize texture transfers between processes.

Clear Cache

Delete the application cache.

Reset All Data

Delete all settings and data, returning to factory defaults.

folder_openWhere to Put Files

  • documents/vmc-swap – Root folder for all custom files
  • documents/vmc-swap/css – Place custom .css files here
  • documents/vmc-swap/crosshair – Place crosshair images (PNG/GIF/APNG) here
  • documents/vmc-swap/swapper-user.json – Custom swap mappings
  • documents/vmc-swap/adblock-user.json – Custom ad block list
These folders are created automatically on first launch. If missing, create them manually.
