settingsクイック設定

主要機能をオン/オフにするマスタースイッチです。変更は再起動後に有効になります。

カスタム十字線

十字線の表示/非表示を切り替えます。詳しくは「十字線」セクションを参照。

カスタムCSS

画面デザインをカスタマイズするCSSの有効/無効を切り替えます。詳しくは「カスタムCSS」セクションを参照。

リソーススワッパー

テクスチャや音を置き換える機能の有効/無効を切り替えます。詳しくは「スワッパー」セクションを参照。変更には再起動が必要です。

広告ブロッカー

広告やトラッカーをブロックする機能の有効/無効を切り替えます。詳しくは「広告ブロッカー」セクションを参照。変更には再起動が必要です。

無制限FPS

FPS制限を解除します。他の詳細設定と同じく、再起動が必要です。

crosshairs十字線（Crosshair）

カスタム十字線機能を使うには、まず「クイック設定」で「カスタム十字線」をONにしてください。

十字線の種類

画像の読み込み方法を3種類から選べます。

  • URL: インターネット上の画像URLを指定します（PNG/GIF推奨）。
  • ローカル: PC内の画像ファイルを選択します（PNG/GIF/APNG対応）。
  • リスト: スワッパーフォルダ内の画像から選択します。

URL / ローカルファイル

画像のアドレスやファイルパスを入力/選択します。

サイズ設定

「自動サイズ検出」にチェックを入れると、画像本来のサイズが自動的に適用されます。
チェックを外すと、手動で幅と高さを設定できます（1px〜1024px）。

不透明度

十字線の透明度を設定します（0 = 透明、1 = 不透明）。

描画方法

画像の拡大・縮小方法を2種類から選べます。

  • ピクセル化: 元のピクセルアート感を保ちます。
  • シャープ: 輪郭がくっきりした表示になります。

brushカスタムCSS

カスタムCSSを使うには、まず「クイック設定」で「カスタムCSS」をONにしてください。

CSSの読み込み方法

3種類の方法でCSSファイルを読み込めます。

  • URL: インターネット上のCSSファイルURLを指定します（CORS対応が必要です）。
  • ローカルファイル: PC内の.cssファイルを指定します。
  • リスト: スワッパーフォルダ内のCSSファイルから選択します。

folder_openスワッパー（リソース置き換え）

スワッパーを使うには、まず「クイック設定」で「リソーススワッパー」をONにしてください。変更は再起動後に有効になります。

フォルダの場所

VoxMateを初めて起動すると、documents/vmc-swapフォルダが自動作成されます。
その中に「css」と「crosshair」フォルダが作られるので、ファイルはそこに置いてください。

デフォルトリストを使う

組み込みのswapper-default.json（中身を確認）に従って置き換えが行われます。

ユーザーリストを使う

自分でswapper-user.jsonを作成して追加できます。
ファイルはdocuments/vmc-swapに置き、内容はJSON形式で記述します。
例:

{ "https://voxiom.io/package/aef55bdd0c3c3c3734f8.png": "soldier_red.png", "https://voxiom.io/sound/weapon.ogg": "weapon_custom.ogg" }

デフォルトリストと重複するURLがある場合、ユーザーリストの値が優先されます。

block広告ブロッカー

広告ブロッカーを使うには、まず「クイック設定」で「広告ブロッカー」をONにしてください。変更は再起動後に有効になります。

デフォルトブロックリストを使う

組み込みのadblock-default.json（中身を確認）に従って広告がブロックされます。

ユーザーリストを使う

自分でadblock-user.jsonを作成して追加できます。
ファイルはdocuments/vmc-swapに置き、内容はJSON形式で記述します。
例:

{ "urls": [ "example.com", "ads.com", "tracking-site.com" ] }

tune詳細設定

ここは上級者向けの設定です。変更には再起動が必要な項目が多いので、慎重に操作してください。

無制限FPS

FPSの制限を解除します。

Discord連携

ゲーム中の状態をDiscordプロフィールに表示します。

GPU Vsync 無効

垂直同期をオフにして、入力遅延を最小化します。

ANGLEバックエンド変更

グラフィックス処理に使うライブラリ（OpenGL/Direct3D）を変更できます。

イープロセスGPU

GPU処理をメインプロセス内で実行します（実験的）。パフォーマンスが向上する場合があります。

QUICプロトコル

ネットワーク通信にQUICプロトコルを使用します。

GPUラスタライゼーション

GPUでラスタライゼーション処理を実行します。

ポインタロックオプション

マウスカーソルをゲーム内でロックできるようにします（FPS向き）。

重い広告対策

ブラウザの重い広告対策機能を有効にします。

GPUブロックリストを無視

ドライバが対応していないと警告されるGPUでも強制使用します。

ゼロコピー転送

プロセス間のテクスチャ転送を最適化します。

キャッシュクリア

アプリケーションキャッシュを削除します。

全データリセット

設定やキャッシュをすべて初期値に戻します。

folder_openファイル置き場

  • documents/vmc-swap – すべてのカスタムファイル置き場
  • documents/vmc-swap/css – カスタムCSSファイル
  • documents/vmc-swap/crosshair – 十字線画像（PNG/GIF/APNG）
  • documents/vmc-swap/swapper-user.json – 自分で追加するスワッパー設定
  • documents/vmc-swap/adblock-user.json – 自分で追加する広告ブロック設定
フォルダはVoxMate初回起動時に自動作成されます。存在しない場合は手動で作成してください。
