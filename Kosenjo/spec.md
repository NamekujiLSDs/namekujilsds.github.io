# システム仕様書 (spec.md)

本ドキュメントは、「古戦場貢献度ランキング（Kosenjo）」を含む各機能の仕様・外部API・データ構造を定義したシステム仕様書です。

---

## 1. 古戦場貢献度ランキング (Kosenjo)

### 1.1 概要
グランブルーファンタジーのイベント「決戦！星の古戦場」において、団員または指定したプレイヤーの貢献度・順位・時速・ボーダー差分を取得し、リアルタイムで一覧表示および将来予測グラフを描画するWebツール。

### 1.2 外部API仕様 (`gbf.pub`)
データ取得元として `https://gbf.pub/api/client/gw/` エンドポイント群を利用。直接アクセスに失敗した場合は `https://api.allorigins.win/raw?url=...` によるCORSプロキシフォールバックを実施。

1. **ボーダーデータ取得**:
   - `GET https://gbf.pub/api/client/gw/line?teamraidid={teamraidid}&type=user&rank={rank}`
   - パラメータ:
     - `teamraidid`: 例 `teamraid082`（第82回の場合）
     - `rank`: 100000（10万位）または 2000（2000位）
2. **ユーザー情報取得**:
   - `GET https://gbf.pub/api/client/gw/user?userid={userid}`
   - プレイヤー名、プロフィール等のメタ情報を取得。
3. **ユーザーポイント履歴取得**:
   - `GET https://gbf.pub/api/client/gw/point?teamraidid={teamraidid}&type=user&id={userid}`
   - 指定イベント期間内の時系列ポイント・順位スナップショット配列を取得。

### 1.3 タイムライン・スケジュールおよび予測モデル仕様
- **タイムライン定義 (EVENT_PHASES / ACTIVE_SEGMENTS)**:
  - 予選: 初日19:00 ～ 2日目23:59 (実経過 0h ～ 29h / 活動時間 0h ～ 29h, 29時間)
  - 予選集計: 3日目00:00 ～ 06:59 (実経過 29h ～ 36h) [空白時間・プロットスキップ]
  - インターバル: 3日目07:00 ～ 4日目06:59 (実経過 36h ～ 60h / 活動時間 29h ～ 53h, 24時間)
  - 本戦1日目: 4日目07:00 ～ 23:59 (実経過 60h ～ 77h / 活動時間 53h ～ 70h, 17時間)
  - 本戦2日目: 5日目07:00 ～ 23:59 (実経過 84h ～ 101h / 活動時間 70h ～ 87h, 17時間)
  - 本戦3日目: 6日目07:00 ～ 23:59 (実経過 108h ～ 125h / 活動時間 87h ～ 104h, 17時間)
  - 本戦4日目: 7日目07:00 ～ 23:59 (実経過 132h ～ 149h / 活動時間 104h ～ 121h, 17時間)
  - ※SPバトル（8日目07:00〜23:59）は貢献度の変動がないため、グラフ描画対象外（ボタンおよびプロット不要）。
- **累積活動時間（Active Timeline）モデル**:
  - 深夜休戦（0:00〜7:00の各7時間）および集計期間を除外した実質稼働時間（0h〜121h）を横軸の基準座標として採用。
  - **全期間グラフ**: 本戦各日の終了点（24:00）と翌朝の開始点（07:00）が同一の活動時間座標で隙間なく直結。夜間の7時間平坦線（水平フラット線）が完全に排除され、活動時間だけが連続して詰まって描画される。
  - **日別グラフ（本戦1〜4日目）**: 選択した日のバトル時間帯（07:00〜24:00、17時間分）のみを抽出し、X軸の表示範囲（min/max）をジャストに一致。深夜0時〜7時は描画領域から完全に除外され、目盛りに余分な夜間時間が一切表示されない。
  - **目盛り（Ticks）フォーマット**: 累積活動時間を実時刻へ逆算し、日別では「07:00」「10:00」...「24:00」と直感的な24時制で表示。全期間では「9/21 19時」「9/22 15時」などの日時形式で表示。
- **空白時間のプロットスキップ仕様**:
  深夜0:00〜翌07:00等のバトル非開催・集計期間（29〜36h, 77〜84h, 101〜108h, 125〜132h, 149h以降）は、グラフのデータポイント（プロット）を一切生成・追加せずスキップする。
- **アクティビティ曲線**:
  過去3回分の同順位ボーダーデータ（過去データ）から、イベント開始からの経過時間ごとの平均増加量（pt/h）を算出してベースラインとする。
- **インフレ率（加速係数）補正**:
  直近12時間の現在開催ボーダー増加量と過去平均の増加量を比較し、倍率（インフレ率）を算出して将来の予測速度に掛け合わせる。
- **個人ペース反映**:
  対象プレイヤーの直近12時間の増加量を基準ボーダーの増加量と比較し、個人の稼働ペース係数（userPace）を算出して予測曲線に反映。
- **期間別・日別 貢献度増加量サマリー表示仕様**:
  - モーダル内グラフ上部（期間タブ直下）に、現在選択されているフェーズ期間内の純増貢献度を表示するバナーコンテナ（`#modalIncreaseSummary`）を常設。
  - **表示項目**:
    - 対象フェーズ名（例: `本戦1日目 増加量`、`全期間 増加量`）
    - ユーザー自身の期間内純増量（赤色: `text-[#ef4444]`）
    - 比較ボーダー（10万位または2000位）の期間内純増量（青色: `text-[#60a5fa]`）
    - 進行中イベントで予測データが存在する場合は、`実績 +X.XX億 (着地予測 +Y.YY億)` を併記。
  - **対応グラフ種別**: 貢献度グラフ（`point`）および時速グラフ（`speed`）の双方において、データ点に保持する累計貢献度を参照し、常に正確な期間内増加量を算出・表示。
- **URL短縮パラメータ仕様（バイナリパック＋Base64url）**:
  - 団員30人分など多数のプレイヤーIDをURLクエリに含める際、長大なURL（270文字超）になるのを防止するため、32bit符号なし整数（4バイト/人）バイナリパック＋URL-safe Base64エンコードによる短縮パラメータ（`?d=...`）を自動適用。
  - **短縮効果**: 30人分のIDリストを約160文字（約40%短縮）に圧縮。
  - **後方互換性**: 3件以下の少数検索時は可読性の高い従来の生カンマ区切り（`?id=...`）を維持し、`?d=...` と `?id=...` の双方から自動判別して復元・解析を実行。
- **ファビコン仕様 (`favicon.svg`)**:
  - 古戦場の星（八点星の黄金の煌めき）と上昇する青のランキング推移バーを組み合わせたダークモード対応のベクターSVGアイコン（`favicon.svg`）を導入。
- **日の切り替わり境界線仕様 (`dayBoundaryLinePlugin`)**:
  - 全期間グラフおよび日をまたぐ予選・インターバルグラフにおいて、各日の境界時刻（24:00 / 翌0:00）に縦方向の破線（`rgba(244, 244, 245, 0.45)`）と日付バッジ（例: `11/22 0:00`）を自動描画。
  - 本戦各日（07:00〜24:00）のような単一日フェーズでは境界線を描画せず、すっきりとした推移線を維持。
- **順位一覧の動的サイズ画像エクスポート仕様 (`exportRankingImage`)**:
  - 10万位・2000位のボーダー行を除外し、登録されているプレイヤーのみを現在のソート順（全体順位、貢献度、時速等）でリスト化。
  - 項目: 順位（#）、プレイヤー名、プレイヤーID、累計貢献度（カンマ区切り実数値および億万略記）。
  - 人数 $N$ および最長の名前長さに応じて Canvas の幅・高さを動的に自動計算。
  - Retina (2xスケール) 対応の鮮明なダークテーマカード風デザインで PNG 画像を生成・自動ダウンロード。

  - **URLパラメータ短縮エンコード（`?d=...`）の実装**:

  - **SVGファビコン（`favicon.svg`）の作成・設置**:
    - 古戦場の星とランキング推移バーを組み合わせた独自SVGファビコンを作成し、HTMLヘッダーへ配置。
  - **期間タブ切り替え時のムチ状モーフィングアニメーション防止**:
    - フェーズごとにデータ点配列の要素数（53件、74件、86件等）が異なるため、タブ切り替え時にデフォルトのモーフィングアニメーションが走るとインデックスのズレで先端が折り返してムチのようにループする不具合を解消。タブ切り替え時は `myChart.update('none')` による即座のクリーン再描画を適用。
  - **増加量サマリー数値のタップによる正確な数値トグル表示**:
    - グラフ上部サマリーの略記表記（例: `+1.5517億`）をタップすることで、生の実数値（例: `+155,170,000`）へ即座にトグル切り替え可能にする機能を実装。
    - 点線アンダーラインとカーソル形状でタップ可能であることを明示し、タブ切り替え後もユーザーの選択モード（略記/詳細）を維持。
  - **全期間グラフにおけるプロット点過密（極太線化）の完全根絶**:
    - 300点以上存在する全期間グラフにおいて、Chart.jsが要素生成時に各点へキャッシュ固定していた `radius`（半径2〜3px）を、データセット設定だけでなく `meta.data[i].options.radius = 0` および動的コールバック関数 `(ctx) => currentSelectedPhaseId === 'all' ? 0 : ...` により強制クリア。
    - 全期間表示時は線の上に並ぶ粒々ドット（プロット点）が1個残らず完全非表示となり、滑らかでスマートな細い折れ線描画を実現。データ数が適度な日別タブ（50〜80点）では各時間のプロット点を視認できるハイブリッド表示を維持。
  - **Chart.js 全体のアニメーション完全無効化（`animation: false`）と斜め線・ループ描画の完全根絶**:
    - `options.animation: false` を初期化オプションへ明示指定することで、初期描画・タブ切り替え・リサイズなどあらゆるタイミングにおける Chart.js のモーフィング補間を完全遮断。日別（52点）から全期間（363点）への切り替え時などに前フェーズの線が斜めに引き延ばされて残る現象を根本解決。

    - 全期間タブおよび日をまたぐ期間（予選、インターバル）において、日付変更時刻（24:00 / 0:00）に視認性の高い破線の垂直線と日付バッジ（例: `11/22 0:00`）を描画する Chart.js プラグインを実装。単一日グラフ（本戦各日）では余計な境界線を描画しない正確なスケール判定を適用。
