# 【仕様書】団活スカウト文面マネージャー (Scout Text Manager)

## 1. プロジェクト概要

* **名称**: 団活スカウト文面マネージャー (Scout Text Manager)
* **目的**: 『グランブルーファンタジー』における団員募集（団活タグへのスカウト）の文面を効率的に管理・選択・コピーするWebツール。
* **背景**: 同一文面の連続投稿によるX（旧Twitter）のスパム判定・シャドウバンを防止するため、多数の言い回しバリエーションを均等にローテーション使用する。
* **稼働環境**: GitHub Pages（静的ホスティング / 完全クライアントサイド完結）。

---

## 2. 要件定義

### 2.1 機能要件 (Functional Requirements)

| ID | 項目 | 内容 |
| --- | --- | --- |
| **FR-01** | **文面自動生成** | 4カテゴリ（計480種、各120種）のユニーク文面をスクリプト内部で動的に構築。 |
| **FR-02** | **使用回数管理** | 各文面のコピー回数を記録し、`localStorage`（キー: `grablue_scout_counts_v2`）に永続化。 |
| **FR-03** | **最少使用優先ソート** | 各カテゴリ一覧において、使用回数が少ない順（昇順）に文面カードを自動整列。同値時は初期順を維持（安定ソート）。 |
| **FR-04** | **クイックコピー** | 各カテゴリに対応した「ワンクリック即時コピー」ボタンを備え、最少使用文面を1クリックでコピーし回数を加算。 |
| **FR-05** | **個別コピー** | 一覧内の各カードにある「コピー」ボタンから、個別にクリップボード転送および回数加算。 |
| **FR-06** | **カテゴリ切替** | タブ操作により、表示対象のカテゴリ（4種）をスムーズに切り替え。 |
| **FR-07** | **カウンターリセット** | 確認モーダルを経由して、保存されている全カウントをゼロに安全に初期化。 |
| **FR-08** | **トースト通知** | コピー成功時に画面下部へ非同期で成功通知（トースト）を1.5秒間表示。 |

### 2.2 非機能要件 (Non-Functional Requirements)

| ID | 項目 | 内容 |
| --- | --- | --- |
| **NFR-01** | **完全スタンドアロン** | 外部DBやサーバーへの依存を排除し、純粋な静的ファイル群（HTML/CSS/JS）で動作。 |
| **NFR-02** | **X文字数制限の厳守** | リプライ用文面（`ikusei_reply`, `ippan_reply`）は、全パーツの組み合わせにおいて140文字（実測114〜129文字）を絶対に超過しない設計。 |
| **NFR-03** | **レスポンシブ対応** | PCおよびスマートフォン（iOS Safari / Android Chrome）での操作に対応。 |
| **NFR-04** | **絵文字完全排除** | 絵文字は一切使用せず、Google Material Symbols Outlinedによる統一UIアイコンを使用。 |

## 3. 業務制約・スカウト方針パラメータ

* **団運営アカウント**: `@grablue_scout`
* **発信元**: 団員の個人アカウント（「詳細は団運営アカウントへDM」を案内する構成）
* **募集区分**:
  1. **育成枠**: 古戦場・ドレバラノルマ免除 / 定期的な装備進捗確認あり / VC相談可能
  2. **一般枠**: 古戦場予選300位目標 / 予選ノルマ5億 / 個ラン10万位以内 / 本戦低空なし / 朝活任意 / Discord VC積極参加

## 4. システムアーキテクチャ & データ構造

### 4.1 ディレクトリ構成
```text
scout/
├── favicon.svg      # ファビコン (SVG)
├── index.html       # メインマークアップ
├── style.css        # Slate 900基調ダークテーマCSS
├── script.js        # 文面生成・状態管理・ソート・クリップボード制御
└── spec.md          # 本仕様書
```

### 4.2 文面データ構造 (`ScoutTextItem`)
```typescript
interface ScoutTextItem {
  id: string;          // 一意識別子 (例: "ir_001", "pd_120")
  cat: CategoryType;   // "ikusei_reply" | "ikusei_dm" | "ippan_reply" | "ippan_dm"
  text: string;        // 結合済みの本文文字列
  length: number;      // 文字数
  initialIndex: number;// 安定ソート用の初期生成インデックス
}
```

### 4.3 ストレージスキーマ
* **Key**: `grablue_scout_counts_v2`
* **Value**: `{ [id: string]: number }`
