# 【仕様書】団活スカウト文面マネージャー (Scout Text Manager) - 騎空団「ENDROLL」

## 1. プロジェクト概要

* **名称**: 団活スカウト文面マネージャー (Scout Text Manager)
* **目的**: 『グランブルーファンタジー』騎空団「ENDROLL」における団員募集（団活タグへのスカウト）の文面および勧誘用バナー画像を効率的に管理・選択・コピーするWebツール。
* **背景**: 同一文面の連続投稿によるX（旧Twitter）のスパム判定・シャドウバンを防止するため、多数の言い回しバリエーションを均等にローテーション使用する。
* **稼働環境**: GitHub Pages（静的ホスティング / 完全クライアントサイド完結）。

---

## 2. 要件定義

### 2.1 機能要件 (Functional Requirements)

| ID | 項目 | 内容 |
| --- | --- | --- |
| **FR-01** | **文面自動生成** | 4カテゴリ（計480種、各120種）のユニーク文面をスクリプト内部で動的に構築。全パーツの結合時に段落改行（`\n\n`）を保持。 |
| **FR-02** | **使用回数管理** | 各文面のコピー回数を記録し、`localStorage`（キー: `grablue_scout_counts_v2`）に永続化。 |
| **FR-03** | **最少使用優先ソート** | 各カテゴリ一覧において、使用回数が少ない順（昇順）に文面カードを自動整列。同値時は初期順を維持（安定ソート）。 |
| **FR-04** | **クイックコピー** | 各カテゴリに対応した「ワンクリック即時コピー」ボタンを備え、最少使用文面を1クリックでコピーし回数を加算。 |
| **FR-05** | **個別コピー** | 一覧内の各カードにある「コピー」ボタンから、個別にクリップボード転送および回数加算。 |
| **FR-06** | **カテゴリ切替** | タブ操作により、表示対象のカテゴリ（4種）をスムーズに切り替え。 |
| **FR-07** | **カウンターリセット** | 確認モーダルを経由して、保存されている全カウントをゼロに安全に初期化。 |
| **FR-08** | **トースト通知** | コピー成功時に画面下部へ非同期で成功通知（トースト）を1.5秒間表示。 |
| **FR-09** | **勧誘画像ランダムコピー** | 5種類の勧誘バナー画像（`scout/images/`）からランダムに画像データをCanvas経由でPNG形式に変換し、ワンクリックでクリップボードへ直接コピー。非対応環境用のプレビューモーダルも装備。 |

### 2.2 非機能要件 (Non-Functional Requirements)

| ID | 項目 | 内容 |
| --- | --- | --- |
| **NFR-01** | **完全スタンドアロン** | 外部DBやサーバーへの依存を排除し、純粋な静的ファイル群（HTML/CSS/JS/PNG/SVG）で動作。 |
| **NFR-02** | **X文字数制限の厳格遵守** | 全文面（480種すべて）において、**改行を含めた合計文字数が厳密に140文字以内（実測115〜132文字）**に収まる設計。 |
| **NFR-03** | **添付画像誘導方針** | 詳しいノルマや方針は添付画像（ENDROLLバナー）に誘導し、簡潔かつ洗練されたスカウト文面を実現。 |
| **NFR-04** | **自然で失礼のない文面** | 相手への過度なお世辞・褒め言葉を排除し、「団員です」等の自己言及も廃止して誠実な騎空団「ENDROLL」としての発信に統一。 |
| **NFR-05** | **レスポンシブ対応** | PCおよびスマートフォン（iOS Safari / Android Chrome）での操作に対応。 |
| **NFR-06** | **絵文字完全排除** | 絵文字は一切使用せず、Google Material Symbols Outlinedによる統一UIアイコンを使用。 |

## 3. 業務制約・スカウト方針パラメータ（添付画像「ENDROLL」準拠）

* **団名**: 騎空団「ENDROLL」
* **誘導先アカウント**: 団運営（`@grablue_scout`）
* **入団条件**:
  - 外部ツール: `Discord`
  - `報連相`ができる方
  - `団内高難易度`等への`積極的`な参加
  - 過去に処罰歴等ない方
* **古戦場方針**:
  - 予選 団順位 `300位 ↑`
  - 本戦: 接戦時協力 `有り` / 低空 `なし` / 朝活 `任意`
* **募集区分**:
  1. **育成枠**:
     - 古戦場・ドレバラ `ノルマ免除`
     - 定期的な`装備進捗の確認・共有`あり
     - `VCでの編成相談・質問歓迎` (意欲重視)
  2. **一般枠**:
     - 古戦場: 予選 `5億` / 個ラン `10万位 ↑`
     - ドレバラ: `最高報酬`貢献度 (頭割り)
